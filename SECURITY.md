# Security Policy

## Supported Versions

| Version / Branch | Python Support | Supported |
|:--- |:--- |:---: |
| `main` (latest) | Python 3.10 – 3.13 | |
| Older branches | < 3.10 | |

## Scope & Operational Notice

This repository provides a numerical engineering simulation suite intended for research, benchmarking, and educational photovoltaic/MPPT studies.
It is not certified firmware for real-time grid-tied inverter hardware protection without independent hardware-in-the-loop (HIL) and IEC/UL compliance qualification.

## Reporting a Vulnerability

If you discover a security vulnerability (e.g., unsafe file parsing, CI workflow permissions issues, or dependency CVEs).
Please report it privately via GitHub's Report a vulnerability advisory tab so a patch can be prepared promptly.
